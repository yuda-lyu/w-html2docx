(async) WHtml2docx(fpInHtml, fpOutDocx, optopt) → {Promise}

Description:

  • Html檔轉Docx檔

    轉檔由htmlToDocx.exe調用本機Microsoft Word(win32com)完成，故須於Windows且已安裝Word之機器執行。htmlToDocx.exe不含於npm包，首次轉檔時經ensureBins自GitHub(釘選提交)或環境變數W_BIN_MIRROR之鏡像取得，以bin/manifest.json之SHA-256與大小校驗後存於快取(預設為套件根之bin-cache/，可由W_BIN_CACHE改位置)，之後自快取取得(亦校驗)；環境變數W_BIN_OFFLINE=1時不連網。取得失敗則reject字串，內含錯誤代碼(如E_OFFLINE_MISSING、E_HASH_MISMATCH)與原因，詳見README〈外部執行檔〉 轉檔器內部失敗(Word未安裝、模板無法開啟、另存失敗等)一律reject並帶轉檔器回報之原因；resolve前另確認輸出檔已產生且非空。輸出資料夾不存在時自動建立

輸入圖片最大高度比例，值介於0至1，圖片最大高度為所在節之版心高乘以0.937043054427296(為圖名預留空間)再乘以本值；有給imgHeightReserveLines且其生效時，改為其算出之高度乘以本值。預設1
imgHeightReserveLines Integer <optional>
 null

輸入行格線模板之圖片下方預留格數，為非負整數，預設null(不啟用)。僅於圖片所在節設有文件格線(Word之「只指定行的格線」「指定行與字元的格線」「文字對齊字元格線」)時生效：圖片最大高度改為(每頁格數－本值)×行距－0.5點，行距為模板之文件格線行距(w:docGrid之w:linePitch)，每頁格數為版心高÷行距之整數部分。行格線下圖片段佔「圖高÷行距」無條件進位之格數，故整頁高之圖下方仍留有本值格數，供間隔段與圖名使用，例如間隔段1格、圖名至多2行時至少給3。格數依實際所佔計，行距18點時12pt中文字每行佔1格、14pt之標楷體每行佔2格。建議再多給1格作為餘裕(如前例給4)：帶段前段後距離之段落會使其後各行不再對齊格線而多佔，頁首頁尾高於邊界時Word亦會縮小本文區，使每頁實際格數少於推算值。給無效值、模板無行格線、或本值不小於每頁格數時不生效，沿用imgRatioHeightMax之預設算法
timeout Number <optional>

(async) autoDownloadFiles() → {Promise}

Description:

  • 取得htmlToDocx.exe的絕對路徑，保留作為舊版對外匯入點之相容層，實際改由ensureBins取得

    舊版於當前工作路徑的src/與node_modules/w-html2docx/src/查找，缺檔時自主幹下載且不校驗；現改經ensureBins：首次使用時自GitHub(釘選提交)或環境變數W_BIN_MIRROR之鏡像取得，以bin/manifest.json之SHA-256與大小校驗後存於快取(預設為套件根之bin-cache/，可由W_BIN_CACHE改位置)，之後自快取取得(亦校驗)，故回傳之路徑位於快取而非src/。不在安裝時下載

    新程式碼請直接調用ensureBins(w-html2docx/src/ensureBins.mjs或WHtml2docx.ensureBins)

    因htmlToDocx.exe只能用於Windows作業系統，故調用前須自行檢核作業系統

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔: 首次使用時下載(或自鏡像取得)並以bin/manifest.json之SHA-256與大小校驗, 之後自快取取得(亦校驗)

    規格: 外部執行檔之存放下載校驗與離線(制式規格)§6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE(共用快取資料夾)、W_BIN_MIRROR(鏡像, 本地資料夾或http(s)網址)、W_BIN_OFFLINE(1為離線), 見README〈外部執行檔〉
